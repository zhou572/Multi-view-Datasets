# Multi-view Datasets
This repository summarizes and standardizes a variety of commonly used public datasets with unified description criteria:
1. Standardize the naming format of all datasets;
2. Denote feature data uniformly as X (number of samples × feature dimension), and labels as Y.

Due to standardized rearrangement, dataset names adopted in my papers may differ from this repository in case or expression. All experimental parameters shall prevail according to the table below. Detailed information of each dataset is shown as follows:
